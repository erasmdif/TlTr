Procedura abilitazione (una tantum)

1) Crea (se serve) un account GitHub: github.com/signup

2) Invia il tuo username a erasmo.difonso@libero.it o su WhatsApp e attendi l’invito al repo TlTr.

3) Vai a Settings → Developer settings → Personal access tokens → Tokens (classic)

4) Clicca Generate new token (classic), scegli una scadenza e spunta lo scope repo (Full control of private repositories). Per repo pubblico basterebbe public_repo, ma repo funziona sempre.

5) Copia il token (si vede una sola volta), incollalo nel campo “GitHub token” qui sopra e premi Load.
