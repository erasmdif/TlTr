Procedura abilitazione (una tantum)
1) Crea un account GitHub (se non ce l’hai): github.com/signup.
2) Completata la procedura di sign-up, invia il tuo username a erasmo.difonso@libero.it o su WhatsApp, e attendi l’invito alla Repository TlTr.
3) Dalla tua immagine del profilo, quindi, apri la sezione per creare token  Settings → Developer settings → Personal access tokens → Fine-grained tokens
4) Crea un token Classic: clicca Generate new token (classic), imposta una scadenza (RICORDA: scaduto il token, dovrai crearne un altro per tornare a modificare), quindi seleziona la casella di spunta di fianco a "repo" (Full control of private repositories).
Nota: se il repo fosse pubblico basterebbe public_repo, ma repo va bene sempre.
5) Copia il token (ATTENZIONE: il sito te lo mostrerà una volta sola, quindi salvalo da qualche parte)
Linee guida di editing
A) Carica il testo → incolla il token che hai ottenuto con la procedura precedente. Il contenuto della sezione note viene caricato nell’editor.
B) Modifica con la toolbar
• Grassetto: seleziona testo → Grassetto (inserisce **…**)
• Evidenza: seleziona testo → !! Evidenzia !! (inserisce !!…!!)
• Elenco puntato: • Elenco (inserisce “- ” all’inizio riga)
• Link: seleziona testo → Link → inserisci URL
• Link invisibile: ((link invisibile)) → incolla URL (restituito come ((https://…)))
• [[modA|…]]: inserisce il richiamo al Modulo A.
C) Preview → premi Preview per vedere il risultato esatto che appare sul sito. Premi di nuovo per tornare in editing.
D) Salva → Save, opzionalmente inserisci un messaggio di commit; le modifiche finiscono su main.
