Che cosa serve
  • Un account GitHub.
  • Essere stati aggiunti come collaboratori al repo erasmdif/TlTr (oppure usare un token “classic” con permesso repo).
  • Un token personale (PAT) da incollare qui sotto per autorizzare le modifiche.
a) Crea un account GitHub

Vai su github.com/signup e completa la registrazione.

Se hai già un account, salta questo passaggio.
b) Mandami il tuo username per l’invito

Scrivimi su WhatsApp o via mail a erasmo.difonso@libero.it col tuo username GitHub. Riceverai un invito come collaboratore al repo.

c) Apri la sezione per creare i token

Dal tuo profilo GitHub: Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic).

d) Crea il token (PAT “classic”)
  1. Dai un nome (es. TlTr editor) e una scadenza.
  2. Spunta lo scope repo (permette lettura/scrittura sul repo invitato).
  3. Genera e copia il token: si vede solo una volta.

Nota: se in futuro sposteremo il repo sotto un’organizzazione potrai usare anche i token fine-grained selezionando l’org e il repo.

e) Usa il token nell’editor

Qui sotto incolla il token, premi Load per caricare il testo, poi Save per salvare. Il token rimane solo nella scheda del browser (sessionStorage).
